# Hermit offline

Run `node unpack-source.mjs` once to restore source files. Use Node 22.18+ or 24 LTS. Install from the desktop package mirror with npm ci, then run npm run open. To run a production build, use npm run build followed by npm start. The local Node server must be running.

Today offers guided reflection. Space includes Fomalhaut, which uses the selected instant and observer. The full GeoNames cities500 and administrative-region data are included for offline location search. Manual coordinates and timezone entry are also available. Use fictional profiles throughout evaluation.

Run npm test, npm run lint and npm run test:browser. Set HERMIT_CHROME_PATH to the bundled Chrome executable on Linux if needed. The project and Fomalhaut code carry MIT notices, HYG data carries CC BY-SA 4.0, GeoNames carries CC BY 4.0, and Swiss Ephemeris has its own terms in ephe/LICENSE.txt.
